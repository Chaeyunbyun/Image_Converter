# Image_Converter
이미지 형식 변환 프로그램 (jpg, jpeg, png, gif, bmp 지원) 

## 사용 방법
1. 파일 선택
   변환할 대상 파일을 선택하여 목록에 추가한다

2. 형식 선택
   콤보 박스에서 변환할 형식(jpg, jpeg, png, gif, bmp)을 선택한다

3. 삭제
   목록의 파일 중 체크한 파일이 목록에서 제거 된다
4. 이미지 변환
   이미지 변환 버튼 클릭 시 [기존 경로], [폴더 선택] 으로 변환 후 파일 위치 선택이 가능하다
   원본 파일 위치에 그대로 저장하고 싶으면 [기존 경로], 별도의 폴더에 저장 시 [폴더 선택] 을 선택한다
   확인 시 체크된 파일이 해당 형식으로 변환되어 저장된다 (원본 파일도 그대로 남아있다)
   변환 완료한 파일은 목록에서 삭제 된다
